# 输入前两字节作 LFSR 初值的密钥流异或：反馈位移位 + ROL + 位交换逐字节还原

## 一句话结论

加密循环对每个输入字节异或一个由 16 位状态寄存器生成的密钥流字节：状态寄存器以明文前两字节（小端拼成 16 位）为初值，每轮把高字节的 tap 位（右移 2/3/1 位异或）反馈进低字节后整体右移 1 位，再对密钥流字节做 ROL1 与 0x33/0x55 掩码位交换；仿写同一状态机即可从密文逐字节还原明文。

## 原理

这不是固定密钥异或，而是自反馈密钥流：`v29` 初值取输入前两字节拼成的 16 位整数，之后每轮 `HIWORD = (v29>>2)^(v29>>3)^(v29>>1)` 与低字拼接后整体 `>>1`——即线性反馈移位寄存器（LFSR），tap 位置固定。密钥流字节还要经 `ROL1` 和 `(v&0x33)`/`(v&0x55)` 式的半字节位交换（本质是 4 位粒度的置换网络）。因为整个密钥流只由前两字节决定，与后续明文无关，所以已知密文长度与算法即可枚举/推断初值（本例由 flag 前缀直接可得 0x66、0x6c）并生成全部密钥流解密。

## 触发条件

- 逆向发现异或值随循环索引变化且带移位/位交换运算，而非常量；
- 伪代码中状态变量初值来自输入头部字节；
- 密文长度已知（本例 42 字节）。

## 利用步骤

1. 在伪代码中定位加密循环：`Buf1[i] = flag[i] ^ (i + f(v29))`，v29 由上一轮移位更新；
2. 抄录反馈式：`h=(v29>>2)^(v29>>3)^(v29>>1)`，拼回 `(h<<16)|l` 后 `>>1` 得新状态；
3. 抄录位操作链：`v34=((hl&0xFF)<<4)|((hl&0xFF)>>4)`（字节内 ROL4/半字节交换），`v35=(4*(v34&0x33))|(v34>>2)&0x33`，密钥流 `=(i+((2*(v35&0x55))|(v35>>1)&0x55))&0xff`；
4. 由已知明文头（flag 前缀）算出 v29 初值，生成 42 字节密钥流与密文逐字节异或；
5. 若初值未知，42 字节输出可按 2 字节初值空间暴力枚举并用可打印性筛选。

## PoC

见方法步骤中的状态机复现脚本结构（16 位 LFSR + ROL4 + 0x33/0x55 位交换 + 索引加法）。

## 变体与关联

- 同类 keystream 场景：xorshift64*、CRC32/MT19937、sbox-ROR 等自生成密钥流（见 ctf/reverse 各 keystream 卡）；
- 初值取自输入前缀的设计使"已知明文前缀"成为必然攻击面；若初值改为随机常量则需枚举 16 位空间。

## 检测与防御

- 教学要点：识别"密钥流生成器 + 逐字节异或"结构的关键是找到状态更新式，位交换链照抄即可，无需理解其密码学意义；
- 防御侧：纯异或流密码密钥流可预测，应换 AES-GCM 等标准算法；初值不应取自可预测输入。
