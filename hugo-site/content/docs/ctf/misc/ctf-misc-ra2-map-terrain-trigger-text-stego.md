## 一句话结论

红警2 地图本身可以藏 flag：出题人在空地/地形上用地图编辑器绘制文字，或配置触发器让“文本触发事件”在条件满足时弹出 `flag{...}`；解题时用地图编辑器查看地形与触发列表，或进游戏完成触发条件即可。

## 原理

- **地图地形层**：红警2 地图由地块/地形对象组成，地图编辑器可以在任意空地绘制像素/文字/图案。它不依赖额外资源，出题成本最低；解题人只要探明地图区域（移除战争迷雾/开全图）或直接看地图文件就能读到。
- **触发器机制**：地图编辑器提供“触发编辑器”，每个触发器由三部分组成：
  - **触发选项**：名称、所属方（如 Russia）、类型、关联触发、是否禁止、难度（简单/中等/困难）等；
  - **条件**：满足什么事件（如某建筑被摧毁、时间到达、单位进入区域）；
  - **结果**：满足条件后执行的动作。结果类型 `11 文本触发事件...` 会显示字符串，参数可直接填 `flag{this_is_a_flag}`（也可引用字符串表）。
- **隐蔽性**：触发器在正常游玩时不会显示在 UI 里，只有满足条件才弹出文本；地图编辑器里则能直接看到触发名称/条件/结果。出题人可把触发命名为 `flag`、挂到某个建筑上，摧毁建筑时弹 flag。
- **为什么能藏住**：普通玩家不会打开地图编辑器，也不会遍历所有触发；只跑图可能错过隐藏区域或触发条件，需要结合编辑器静态分析。

## 触发条件

- 题目附件是红警2 地图（`.map`/`.mpr`）或包含地图的资源包；可用地图编辑器（FinalAlert 2 等）打开。
- 地图中有可疑空地文字、未使用区域，或触发器列表里有 `flag`/`text` 等命名。
- 触发器结果类型为文本事件，参数含 flag；或条件指向某个可摧毁建筑/区域。
- 也可以进游戏，按触发器条件操作（摧毁指定建筑/进入区域）触发文本。

## 利用步骤

1. 用地图编辑器打开附件地图，先看整体地形和未探索区域，寻找空地绘制的文字/图案。
2. 打开“触发编辑器”，逐个查看触发器：
   - “触发选项”看名称、所属方、关联触发；
   - “条件”看触发时机；
   - “结果”看行为类型，重点找 `11 文本触发事件...` 及其“文本”参数。
3. 若结果参数引用字符串表，转到字符串表/地图内文本资源查对应内容；若是字面量，直接读 `flag{...}`。
4. 若不想静态分析，进游戏按条件操作（如摧毁触发关联的建筑），等待文本弹出；可用修改器开全图/加速。
5. 记录触发器名称、所属方、关联触发 ID，便于在多张地图/多个触发之间交叉定位。

## PoC

触发编辑器中的典型配置（原文截图）：

```text
触发选项:
  名称: flag
  所属方: Russia
  类型: 0
  关联触发: 01000000 (flag)
  简单 / 中等 / 终结 勾选

结果:
  行为类型: 11 文本触发事件...
  行为参数: 文本 = flag{this_is_a_flag}
  说明: 显示字符串文件内<相应项目>的文本内容
```

本卡为地图编辑器操作，无通用代码 PoC；地图/触发格式随版本/编辑器不同，需按实际工具查看。

## 变体与关联

- 变体：空地绘制文字/二维码/箭头；把 flag 拆成多段放在不同区域，需拼图。
- 变体：触发器条件改为时间、单位进入区域、建筑被摧毁、开关被触发；结果类型除文本外还可能是播放语音/显示简报/给予单位。
- 变体：触发器名称/关联 ID 故意误导，flag 在另一个触发里；需要遍历全部触发而不是只看名字。
- 关联：[[ctf-misc-ra2-billboard-shp-animation-stego]]（SHP 广告牌）、[[ctf-misc-ra2-vxl-model-bottom-text-stego]]（VXL 模型底部）。
- 边界：地图编辑器版本不兼容可能打不开；触发器文本可能引用外部字符串表；加密/打包的地图需先解包。

## 检测与防御

- CTF 识别：地图有空地文字、触发器列表异常、结果类型为文本事件；优先用地图编辑器静态检查。
- 取证：保留原始地图，导出触发器列表与地形截图；记录触发 ID/名称/条件/结果，避免遗漏。
- 防御：比赛附件校验地图哈希/签名；服务端只加载官方地图；对自定义地图做触发器/资源审计。
