## 一句话结论

当密文由带点/不带点的九宫格类符号组成、且被手写排成三列时，先按猪圈（Pigpen）变体表把每个符号映射成字母，再按三列栅栏的读取顺序（逐行跨列或逐列）还原明文；本题得到 `WELCOMETOSIGNUP`。

## 原理

- **猪圈密码（Pigpen）**：把 26 个字母分配到 3×3 网格的 9 个格子/四个方位中，每个格子再分“有点/无点”或不同朝向，形成 26 个符号。不同题目会使用不同变体（网格形状、点的位置、字母顺序），所以不能死记标准表，要按题目给的 hint 图/密文形态匹配。
- **三列栅栏**：题干提示“栅栏”且密文被排成三列。换位密码不改变字母频率，只是改变读取顺序；先解替换（符号→字母），再按栅栏的两种常见读法（逐列读、逐行跨列读）尝试，得到可读英文。
- **为什么成立**：古典替换密码的密钥空间很小，符号表一旦泄露/被识别，映射是确定性的；三列栅栏只是换位。先解替换、再解换位即可，不需要穷举全部密钥。
- **识别信号**：符号数量有限（约 26 种）、由几何框架/点组成、重复模式符合英文单词（如 `WELCOME`、`SIGNUP`）、题干出现“猪圈/栅栏/三列/划痕”等提示。

## 触发条件

- 密文由几何符号组成，符号种类有限，字母频率/单词模式可辨；有 hint 图或已知字母表。
- 题目明确或暗示“栅栏/猪圈/三列”等结构。
- 明文为英文短句/flag 包裹（本题 `0xGame{...}`）。
- 符号是手写/图片时，需要先逐符号辨认（点位置、朝向、边框）。

## 利用步骤

1. 统计符号种类与重复模式，判断是替换类古典密码；结合题干/hint 图区分猪圈、栅栏、凯撒等。
2. 找题目给出的符号表（本题图 03 是 A–Z 的猪圈变体表），建立符号→字母映射。
3. 按三列栅栏的两种读法尝试：逐列读、逐行跨列读；若得到可读英文则停止。
4. 用 `0xGame{...}` 包裹验证答案；本题还原为 `0xGame{WELCOMETOSIGNUP}`。
5. 若符号辨认有歧义，用已知单词/字母频率交叉校验，必要时尝试镜像/旋转变体。

## PoC

无脚本 PoC；本题为手工/查表解码，最终答案：

```text
0xGame{WELCOMETOSIGNUP}
```

## 变体与关联

- **变体（标准猪圈）**：3×3 网格 + 四方位，共 26 个符号；不同字母表顺序会产生不同映射。
- **变体（带点/朝向）**：点在内/外、开口方向、边框形状都可编码；先确定变体再查表。
- **变体（栅栏/换位）**：三列只是栅栏的一种；还可能是按行写、按列读，或反向读取。
- **关联卡片**：[[crypto-aes-cbc-known-key-constraint-plaintext-forgery]]（同一篇的另一类“已知信息构造”题）；古典密码卡目前较少，本卡可作为 CTF Misc/Crypto 的识别入口。
- **边界**：符号表未知且 hint 不足时需要先破译符号；若密文是纯图片且符号模糊，辨认错误会导致错误映射；替换+换位的组合需要两种读法都尝试。

## 检测与防御

- **CTF 识别**：图片中出现九宫格/带点符号、题干提到“栅栏/猪圈/三列”，优先按本卡流程解码。
- **现实安全**：古典替换/换位密码不能用于保护敏感数据；使用现代 AEAD/签名方案。
- **教学**：符号密码的价值在于识别与频率分析，不要把它当作安全机制；对 hint 图/符号表做来源校验，避免被误导。
