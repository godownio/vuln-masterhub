## 一句话结论

当程序对结构化文件（如 xlsx）逐单元格施加确定性、与位置/顺序无关的"加密"且加密程序在手时，可把加密程序当作黑盒：自造一份含已知数值（1-10、带小数、同列重复值）的输入文件跑一遍，比对输出即可确认"同输入必同输出、与行列位置无关"，再将输入输出对交给多项式拟合恢复解析式（此处 y=5x²+2x+1），最后求根公式逐值还原原始数据。

## 原理

- **确定性变换必然留下可探测性**：题目设定是"源数据被删、只剩 enc.xlsx 与加密程序"。只要加密不引入随机 salt/IV、不依赖单元格坐标与顺序（逐值独立变换），它就是数学函数 f(x)；对任意可自选的 x 都能观测到 f(x)——这就是选择明文攻击条件。
- **用对照实验确认函数性质**：构造输入文件，含 ① 整数序列 1..10（低次多项式拟合的最小充分样本）、② 多个小数点后多位的值（判定是否区分浮点/整数路径）、③ 同列重复值与跨列相同值（判定 f 是否与列/行位置相关）。若输出中相同输入给出相同输出、两列规律一致，即可断定 f 是逐值纯函数。
- **拟合与求逆**：3 个样本即可唯一确定二次多项式；把样本喂给符号/数值工具（此例直接由 GPT 拟合）得到 `f(x)=5x²+2x+1`，验证 1→8、2→25、…、10→521 全对。求逆用求根公式取正根：`x=(-2+sqrt(4-20(1-y)))/10`，浮点误差用 round 到 6 位处理。
- **任务收口**：还原全部数据后按题意求两列均值、保留 3 位小数拼接 `2.000,3.000` 样式的字符串再取 MD5 即得 flag。攻击全程无需理解 MATLAB 代码内部实现（题目提示 SMC/自修改代码，静态分析成本高，黑盒法完全绕开）。

## 触发条件

- 加密程序可本地运行且接受攻击者可控的输入文件（或任何可重复喂入的接口）。
- 变换为确定性纯函数：无随机化、不依赖记录顺序/坐标（可用重复值对照验证）。
- 输出精度足以区分候选拟合式（浮点输出高位有效数字即可）。

## 利用步骤

1. 运行程序得到"缺少 flag.xlsx"等提示，确认输入文件名与格式；用 enc.xlsx 复制改名得到合法模板。
2. 构造探测文件：A/B 列填 1..10，再插入 1.5、1.05、1.005、10.5 等小数及同列重复值、跨列相同值。
3. 运行加密，对比输出：相同输入→相同输出、两列变换一致 ⇒ 逐值确定函数。
4. 将 (x, f(x)) 样本交给拟合（拉格朗日/最小二乘/符号回归均可），得到 y=5x²+2x+1 并在多组样本上验证。
5. 对 enc.xlsx 每个值用求根公式取正根还原 x，浮点值 round 保留必要精度。
6. 按题目要求统计（均值、保留 3 位小数、拼接、MD5）得到最终答案。

## PoC

还原函数（对应 y=5x²+2x+1 的逆）：

```python
import math
def inv(y):
    d = 4 - 20 * (1 - y)
    if d < 0: return None
    return (-2 + math.sqrt(d)) / 10
# 验证：inv(8)=1, inv(25)=2, inv(521)=10
vals = [24.890125, 1084.192, 89.210125]  # enc.xlsx 任取
print([round(inv(v), 6) for v in vals])
```

## 变体与关联

- 变体：f 含分段（整数/浮点不同式）时，按数据类型分组分别拟合；样本不足时按先验约束（值域、单调性）筛选。
- 变体：无法整文件重跑时，用程序支持的任意可注入输入通道（导入、粘贴板、CSV）做同等探测；Excel 函数类题目可对照公式审计。
- 变体：若 f 不可逆（有损），退化为在值域内枚举/优化匹配（如 f(x)=x² 丢符号时按业务约束选根）。
- 关联：`[[ctf-misc-excel-neural-network-weight-reversal]]`（xlsx 内容驱动的另一类恢复）、`[[ctf-reverse-blackbox-chosen-input-mapping]]`、`[[crypto-implementation]]` 层的确定性加密缺陷（无 salt 逐值可逆变换）。
- 边界：加密含随机 salt/IV、依赖单元格坐标或链式依赖前后单元格时，逐值函数假设破产，需转向逆向程序本身；MATLAB 打包程序若校验文件哈希/来源会阻断构造输入。

## 检测与防御

- 数据保护：对敏感数据的变换必须加入随机化（每记录 salt）与位置绑定（HMAC 含行号/列名），使黑盒探测无法建立可复用映射。
- 程序保护：校验输入文件来源/签名，限制对可执行程序的自动化喂入；发布混淆（如 MATLAB 加密仍可被黑盒探测，重点在数据层防御）。
- 检测：数据文件异常访问模式（短时间内大量小规模试探性输入输出）可作为黑盒探测的行为特征。
