# 安全知识库

## 这层是什么

按安全类型组织的场景卡片树。每个目录的 README 说明该层范围，卡片是原子拆解单位。

## 顶层目录

- [Web 安全](web/README.md) —— Web 应用漏洞、框架/组件利用、协议与认证、注入与文件类问题。
- [代码分析](code-analysis/README.md) —— 代码审计、逆向工程、脱壳、混淆、动态分析与漏洞挖掘。
- [二进制安全](binary/README.md) —— Pwn、堆栈利用、内核、浏览器与沙箱逃逸。
- [密码学](crypto/README.md) —— 密码学攻击、协议缺陷与实现问题。
- [AI 安全](ai-security/README.md) —— 大模型、Agent、RAG、MCP 与供应链安全。
- [移动安全](mobile/README.md) —— Android、iOS、HarmonyOS 应用与系统安全。
- [云安全](cloud/README.md) —— 云原生、容器、Kubernetes、CI/CD 与 IAM。
- [IoT/工控](iot/README.md) —— 固件、协议、硬件与工业控制系统安全。
- [区块链](blockchain/README.md) —— 智能合约、DeFi、钱包与共识安全。
- [渗透测试](pentest/README.md) —— 红队与渗透流程、权限提升、横向与持久化。
- [CTF](ctf/README.md) —— CTF 题型技巧与快速解法。
- [防御](defense/README.md) —— 检测、加固、应急响应与取证。
- [工具](tools/README.md) —— 安全工具的高级用法与脚本。
